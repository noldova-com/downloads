# Downloads

Official builds of Noldova's apps.

Each release is tagged `<app>-<version>`, such as `teamrun-0.0.1`, and holds that version's installers and update files, each with its SHA-256 in a `.sha256` file beside it.

To install an app, use its download page:

- TeamRun: https://teamrun.noldova.com

Installed apps update themselves from these releases.

This repository holds no source code. Report a problem in the app's own repository.
